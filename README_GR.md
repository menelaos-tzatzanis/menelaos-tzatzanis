# Menelaos Tzatzanis

[English](README.md) · [Ελληνικά](README_GR.md)

Δημιουργώ **εφαρμογές Windows με έμφαση στη διαχείριση πελατών, τα ραντεβού, τα αρχεία, τις οικονομικές ροές και πρακτικά εργαλεία για επαγγελματίες και μικρές επιχειρήσεις**.

Στόχος μου είναι να δημιουργώ λογισμικό καθαρό, χρήσιμο και εύκολο στην καθημερινή χρήση — χωρίς περιττή πολυπλοκότητα.

## Τι δημιουργώ

Τα projects μου επικεντρώνονται κυρίως σε:

- Διαχείριση πελατών και πελατολογίου
- Ραντεβού και προγραμματισμό
- Ιστορικό και αρχεία πελατών
- Υπηρεσίες και καθημερινές επαγγελματικές ροές
- Παρακολούθηση εσόδων και οικονομικών στοιχείων
- Σημειώσεις, έγγραφα και αναφορές
- Backup, εξαγωγές και τοπική διαχείριση δεδομένων
- Εξειδικευμένα εργαλεία για διαφορετικές επαγγελματικές ανάγκες

Οι περισσότερες desktop εφαρμογές μου ακολουθούν **local-first** προσέγγιση και είναι σχεδιασμένες ώστε να λειτουργούν κανονικά χωρίς να εξαρτώνται από cloud account, απομακρυσμένη βάση δεδομένων ή συνεχή σύνδεση στο Internet.

Είναι σχεδιασμένες για **Windows PCs και Windows tablets**, με υποστήριξη **Αγγλικών και Ελληνικών**.

Για μελλοντικές εμπορικές εκδόσεις, η κατεύθυνση είναι απλή: **εφάπαξ αγορά, τοπική εγκατάσταση και χωρίς υποχρεωτική συνδρομή για να συνεχίσει ο χρήστης να χρησιμοποιεί την έκδοση που αγόρασε**.

Ανάλογα με το προϊόν και τις ανάγκες του χρήστη, μπορούν μελλοντικά να προστεθούν προαιρετικές λειτουργίες ή πιο προσαρμοσμένες δυνατότητες.

## Επιλεγμένα Projects

### [ORDINOX Desk Therapist](https://github.com/menelaos-tzatzanis/ORDINOX-Desk-THERAPIST)

Local-first εφαρμογή Windows για θεραπευτές και επαγγελματίες ψυχικής υγείας.

Συγκεντρώνει διαχείριση πελατών, προγραμματισμό συνεδριών, ιστορικό, attendance, σημειώσεις, έγγραφα, οικονομικά στοιχεία, στατιστικά, treatment planning, exports, backup και άλλα εργαλεία γραφείου σε ένα ενιαίο desktop περιβάλλον.

**Εστίαση:** θεραπευτικά γραφεία, πελατολόγιο, προγραμματισμός και οργάνωση πρακτικής.

---

### [Ordinox Desk](https://github.com/menelaos-tzatzanis/ordinox-desk)

Γενικού σκοπού desktop εφαρμογή διαχείρισης πελατών και καθημερινών λειτουργιών μικρών επιχειρήσεων.

Συνδυάζει πελατολόγιο, ραντεβού, υπηρεσίες, οικονομικές πληροφορίες, υπενθυμίσεις, ιστορικό και εργαλεία backup σε ένα πρακτικό τοπικό περιβάλλον.

**Εστίαση:** διαχείριση πελατών και καθημερινή οργάνωση μικρών επιχειρήσεων.

---

### [Ordinox Desk Lite](https://github.com/menelaos-tzatzanis/ordinox-desk-lite)

Ελαφριά εφαρμογή διαχείρισης πελατών και επιχείρησης, σχεδιασμένη γύρω από τις ανάγκες οπτικών καταστημάτων.

Περιλαμβάνει πελατολόγιο, στοιχεία οπτικής συνταγής, ιστορικό επισκέψεων, υπηρεσίες, εργαλεία εσόδων και τοπικό backup/import.

**Εστίαση:** οπτικές επιχειρήσεις, αρχεία πελατών και ιστορικό υπηρεσιών.

## Κατεύθυνση

Με ενδιαφέρει η δημιουργία πρακτικών desktop εφαρμογών που μπορούν να προσαρμόζονται σε διαφορετικά είδη επιχειρήσεων και επαγγελματικών ροών.

Η βασική ιδέα δεν είναι απλώς μια λίστα πελατών, αλλά η συγκέντρωση γύρω από κάθε πελάτη των πληροφοριών και ενεργειών που χρειάζεται ο χρήστης — ραντεβού, αρχεία, υπηρεσίες, σημειώσεις, ιστορικό, οικονομικά και άλλα χρήσιμα εργαλεία.

Μελλοντικά projects μπορούν να απευθυνθούν και σε άλλους επαγγελματικούς κλάδους ή να περιλαμβάνουν προαιρετικές λειτουργίες ανάλογα με τις ανάγκες των χρηστών.
