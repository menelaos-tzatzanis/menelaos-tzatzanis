## Τι Συνδέει τη Δουλειά μου

**Πρακτική οργάνωση.** Οι σχετικές πληροφορίες και ενέργειες χρειάζεται να βρίσκονται μαζί, είτε αφορούν πελάτες και ραντεβού είτε φωτογραφίες, βίντεο και ήχο.

**Τοπική λειτουργία.** Πολλές από τις εφαρμογές μου διαχειρίζονται τα δεδομένα τοπικά, χωρίς να απαιτούν λογαριασμό cloud ή συνεχή σύνδεση στο Internet για τη βασική χρήση.

**Στοχευμένη ανάπτυξη.** Εργάζομαι σταδιακά, με προσοχή στην ευχρηστία, στη διαχείριση δεδομένων και στη διατήρηση της υπάρχουσας λειτουργικότητας.

Οι εφαρμογές αναπτύσσονται για Windows. Η υποστήριξη γλωσσών και η καταλληλότητα για διαφορετικούς τύπους συσκευών, συμπεριλαμβανομένων των Windows tablets, εξαρτώνται από το κάθε προϊόν.

Ανάλογα με το έργο, χρησιμοποιώ:

**Tauri · Rust · SQLite · React · TypeScript · JavaScript · HTML · CSS**

Η δουλειά μου περιλαμβάνει επίσης τοπικά εργαλεία επεξεργασίας πολυμέσων, εισαγωγή και εξαγωγή δεδομένων, αντίγραφα ασφαλείας και δημιουργία πακέτων εγκατάστασης για Windows.

Χρησιμοποιώ εργαλεία υποβοήθησης ανάπτυξης με τεχνητή νοημοσύνη, σε συνδυασμό με χειροκίνητη επαλήθευση, έλεγχο κώδικα, δοκιμές και αποφάσεις σχεδιασμού του προϊόντος.
