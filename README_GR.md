# Μενέλαος Τζατζάνης

[English](README.md) · [Ελληνικά](README_GR.md)

Δημιουργώ **πρακτικές desktop εφαρμογές για Windows με αντικείμενο την οργάνωση media, τη διαχείριση πελατών και επιχειρήσεων, τον προγραμματισμό, τα αρχεία και εξειδικευμένες καθημερινές ροές εργασίας**.

Στόχος μου είναι να δημιουργώ λογισμικό καθαρό, χρήσιμο και εύκολο στην καθημερινή χρήση — χωρίς περιττή πολυπλοκότητα.

Τα projects μου δεν περιορίζονται σε ένα μόνο είδος λογισμικού. Ορισμένα επικεντρώνονται σε επαγγελματικές και επιχειρηματικές ροές, ενώ άλλα αφορούν προσωπικά media, τοπική οργάνωση δεδομένων και διαφορετικές desktop χρήσεις.

## Τι δημιουργώ

Τα projects μου μπορούν να περιλαμβάνουν περιοχές όπως:

- Οργάνωση φωτογραφιών, βίντεο και audio
- Τοπικές media libraries
- Διαχείριση πελατών και πελατολογίου
- Ραντεβού και προγραμματισμό
- Ιστορικό και αρχεία πελατών
- Προϊόντα, υπηρεσίες και επιχειρηματικές ροές
- Παρακολούθηση εσόδων και οικονομικών στοιχείων
- Σημειώσεις, έγγραφα και αναφορές
- Αναζήτηση, φίλτρα και εργαλεία οργάνωσης
- Backup, exports και τοπική διαχείριση δεδομένων
- Εξειδικευμένα εργαλεία για διαφορετικές επαγγελματικές ή προσωπικές ανάγκες

Πολλές από τις desktop εφαρμογές μου ακολουθούν **local-first** προσέγγιση και είναι σχεδιασμένες ώστε να λειτουργούν κανονικά χωρίς να εξαρτώνται από cloud account, απομακρυσμένη βάση δεδομένων ή συνεχή σύνδεση στο Internet.

Η τρέχουσα δουλειά μου επικεντρώνεται κυρίως σε **Windows desktop εφαρμογές**, για desktop υπολογιστές, laptops και, όπου είναι κατάλληλο, Windows tablets.

Η γλωσσική υποστήριξη εξαρτάται από το κάθε προϊόν. Ορισμένες εφαρμογές υποστηρίζουν **Αγγλικό και Ελληνικό περιβάλλον**, ενώ άλλες χρησιμοποιούν προς το παρόν μία βασική γλώσσα interface.

Για μελλοντικές εμπορικές εκδόσεις, η γενική κατεύθυνση είναι απλή: **τοπική εγκατάσταση, εφάπαξ αγορά όπου είναι κατάλληλο και χωρίς υποχρεωτική συνεχή συνδρομή μόνο και μόνο για να συνεχίσει ο χρήστης να χρησιμοποιεί την έκδοση που αγόρασε**.

Ανάλογα με το προϊόν και τις ανάγκες του χρήστη, μπορούν επίσης να αναπτυχθούν πρόσθετες προαιρετικές λειτουργίες ή πιο προσαρμοσμένες δυνατότητες.

## Επιλεγμένα Projects

### [MyMediaManager](https://github.com/menelaos-tzatzanis/My-Media-Manager)

Local-first desktop εφαρμογή Windows για οργάνωση φωτογραφιών, βίντεο και audio σε μία δομημένη βιβλιοθήκη.

Συνδυάζει albums, nested albums, tags, favorites, People / Faces, υποβοηθούμενη offline αναγνώριση προσώπων, προηγμένη αναζήτηση, τοπικό Phone Import, εργαλεία επεξεργασίας φωτογραφιών, playlists, slideshow, exports, backup και εργαλεία συντήρησης της βιβλιοθήκης.

Η εφαρμογή υποστηρίζει τόσο Linked media, που μπορούν να παραμένουν στους υπάρχοντες φακέλους τους, όσο και Managed media που αποθηκεύονται μέσα στη δική της βιβλιοθήκη.

**Εστίαση:** προσωπική οργάνωση media, local media ownership και πρακτική διαχείριση βιβλιοθήκης.

---

### [ORDINOX Desk Therapist](https://github.com/menelaos-tzatzanis/ORDINOX-Desk-THERAPIST)

Local-first εφαρμογή Windows για θεραπευτές και επαγγελματίες ψυχικής υγείας.

Συγκεντρώνει διαχείριση πελατών, προγραμματισμό συνεδριών, ιστορικό, attendance, σημειώσεις, έγγραφα, οικονομικά στοιχεία, στατιστικά, treatment planning, exports, backup και άλλα εργαλεία γραφείου σε ένα ενιαίο desktop περιβάλλον.

**Εστίαση:** θεραπευτικά γραφεία, πελατολόγιο, προγραμματισμός και οργάνωση πρακτικής.

---

### [Ordinox Desk](https://github.com/menelaos-tzatzanis/ordinox-desk)

Γενικού σκοπού local-first εφαρμογή Windows για διαχείριση πελατών και καθημερινή οργάνωση μικρών επιχειρήσεων.

Συνδυάζει πελατολόγιο, ραντεβού, υπηρεσίες, οικονομικές πληροφορίες, υπενθυμίσεις, ιστορικό και εργαλεία backup σε ένα πρακτικό desktop περιβάλλον.

**Εστίαση:** διαχείριση πελατών και καθημερινή οργάνωση μικρών επιχειρήσεων.

---

### [Ordinox Desk Lite](https://github.com/menelaos-tzatzanis/ordinox-desk-lite)

Ελαφριά local-first εφαρμογή Windows για διαχείριση πελατών, προϊόντων ή υπηρεσιών, ιστορικού, τιμών και εσόδων σε διαφορετικά είδη μικρών επιχειρήσεων.

Το παράδειγμα οπτικού καταστήματος που παρουσιάζεται στο project είναι μία ενδεικτική διαμόρφωση, ενώ η βασική εφαρμογή μπορεί να προσαρμόζεται σε διαφορετικές επαγγελματικές ανάγκες.

**Εστίαση:** πρακτική διαχείριση πελατών και μικρών επιχειρήσεων.

## Κατεύθυνση

Με ενδιαφέρει η δημιουργία πρακτικού desktop λογισμικού γύρω από πραγματικές ανάγκες και ροές εργασίας, χωρίς να περιορίζομαι σε μία μόνο κατηγορία εφαρμογών.

Ορισμένα projects επικεντρώνονται στην επαγγελματική ή επιχειρηματική οργάνωση, ενώ άλλα εξερευνούν περιοχές όπως η προσωπική διαχείριση media, οι τοπικές ροές αρχείων και πιο εξειδικευμένα desktop εργαλεία.

Μια κοινή ιδέα σε πολλά από αυτά τα projects είναι η συγκέντρωση σχετικών πληροφοριών και ενεργειών σε ένα καθαρό περιβάλλον — είτε πρόκειται για πελάτες, ραντεβού και αρχεία είτε για φωτογραφίες, βίντεο, audio, albums, tags και αναζήτηση.

Μελλοντικά projects μπορούν να απευθυνθούν σε επιπλέον επαγγέλματα, προσωπικές ανάγκες ή άλλες desktop χρήσεις.

## Προσέγγιση Ανάπτυξης

Η ανάπτυξη των εφαρμογών γίνεται γενικά σταδιακά.

Προτιμώ να:

- Κατανοώ πρώτα την υπάρχουσα συμπεριφορά
- Κάνω στοχευμένες αλλαγές
- Ελέγχω τις επηρεαζόμενες ροές
- Εξετάζω πιθανά side effects
- Προστατεύω τα υπάρχοντα δεδομένα και τη λειτουργικότητα
- Αποφεύγω περιττά μεγάλα rewrites
- Βελτιώνω το usability χωρίς να θυσιάζω την αξιοπιστία

Αυτό είναι ιδιαίτερα σημαντικό σε desktop εφαρμογές που διαχειρίζονται τοπικά δεδομένα του χρήστη.
